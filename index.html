    Featured Project

    ALMA Plugin

    ALMA is an all-in-one mixbus processing unit developed in C++ and JUCE. Each of its 5 core macro modules handles a parallel chain of 3 independent effects, allowing users to toggle, stack, and fine-tune individual sub-parameters. It features an adaptive UI layer ("ALMA mode") that translates standard DSP parameters into intuitive terminology for beginners. It includes a factory bank and native custom preset serialization.
